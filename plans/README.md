## Findings considered and rejected

- **Committed credentials in .env** (security auditor): FALSE POSITIVE —
  `.env` exists on disk only; `git log --all -- .env` is empty, it was never
  tracked, and `.gitignore` covers it. No rotation emergency. (Do keep it
  out of the repo.)
- **SSR crash at `render.ts` renderRows** (`response?.resultSets.filter`):
  FALSE POSITIVE — `resultSets` is non-optional on `SearchResponse`
  (`src/models.ts:90`) and optional chaining short-circuits the whole chain.
- **Stale suggest render after abort**: FALSE POSITIVE — guards already
  present (`requestAbort.signal.aborted`, `suggestAbort !== requestAbort`,
  input-value equality) before rendering.
- **Debug panel exposes provider response metadata**: by design — the
  flip-to-debug panel is a documented feature (README "Debug"); no secrets
  in the payload.
- **`"local"` string in debug responseStatus**: intentional labeling of the
  key-free DuckDuckGo path; debug-only field.
- **/lanes shared-credential architecture**: real trade-off but decided —
  server-only shared login is the documented design; per-user Clubspot
  OAuth isn't offered by the upstream. Revisit only if Clubspot exposes
  per-user tokens.
- **CORS headers missing on /api**: absence of `Access-Control-Allow-Origin`
  is already the restrictive browser default; adding CORS would loosen, not
  harden. Folded the real residue (response-hardening headers) into 008.
- **Bundle code-splitting** (client.js ships voice/AI/all commands): real
  but L-effort with UX risk; revisit after 002/004 shrink client.ts.
  Recorded, not planned.
- **Regex hoisting / highlight memoization / DOM query caching /
  localStorage eviction / result pagination** (perf auditor): micro or
  speculative at current scale (≤50 results, per-keystroke work already
  cheap); not worth executor cycles now.
- **Defensive-only correctness items** (PROMPT_MODES non-null asserts,
  debug trace index assignment, detached-node cleanups, lanes
  formatToParts hardening): low value or speculative; rejected to keep the
  fix plan honest.
- **Transformers 4.x upgrade now**: deferred to an investigation step inside
  plan 009 — version claim came from auditor memory, and the worker code is
  only manually verifiable.
- **actions/checkout@v5 bump**: cosmetic; fold into normal maintenance.
- **Session persistence/export and a community plugin loader**
  (direction auditor): grounded but large (L) and strategy-level; surfaced
  to the maintainer in the audit report instead of planned. Ask for a spike
  plan if wanted.
